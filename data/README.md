# Data

## English

This project does not use an external observational dataset. The Python
programs generate synthetic graph structures, Gaussian noise, and anomaly
signals in memory from fixed random seeds. The generated row-level and
aggregated outputs are preserved under `results/`.

Consequently, an empty `data/` directory is intentional: there are no missing
raw input files and no personal or confidential data. For a Zenodo Dataset
deposit, use the separately prepared dataset archive containing the preserved
CSV tables, figures, provenance notes, and checksums.

## Русский

В проекте не используется внешний наблюдательный набор данных. Программы
Python генерируют синтетические графы, гауссовский шум и аномальные сигналы в
памяти с фиксированными начальными значениями генераторов случайных чисел.
Построчные и агрегированные результаты сохранены в каталоге `results/`.

Поэтому пустой каталог `data/` является осознанным решением: отсутствующих
входных файлов, персональных или конфиденциальных данных нет. Для публикации
Zenodo Dataset следует использовать отдельно подготовленный архив данных с
CSV-таблицами, рисунками, описанием происхождения и контрольными суммами.
